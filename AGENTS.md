# alive

`alive` — долгоживущий автономный агент на базе `@earendil-works/pi-coding-agent`: непрерывно работает, ждёт события и сохраняет память между сбросами контекста. Проект написан на TypeScript; основные части — runtime, хранилище и модули каналов связи (в частности Telegram).

## Правила работы над репозиторием

- Задачи берутся из GitHub issues с меткой `ready`; приоритеты `p0`–`p3`.
- Ветки: `feature/*`, `fix/*`, `release/YYYY-MM-DD`. Прямой push в `master` — только
  через мерж проверенного PR с пройденными `typecheck` и релевантными тестами.
- Ядро (`src/`, runtime-конфиги, контракты агентов) меняется только с явным ок владельца.
- **Теги обязательны.** Релизный мерж в `master` завершается поднятием `version` в
  `package.json` и аннотированным тегом `vX.Y.Z` на том же коммите. Тег нужно запушить:
  `alive update` видит только remote-теги. Без тега обновление харнесса невозможно,
  поэтому «влил и забыл» — не готово.
